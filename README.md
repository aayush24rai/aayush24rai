### 🧩 Selected Projects

**🔥 [HeatSwitch](https://github.com/aayush24rai/heatswitch)** · [Live app](https://heatswitch-five.vercel.app) · [Demo](https://youtu.be/c6uy_ZNdKJ0)
Tells Boston residents whether a heat pump actually saves them money. Upload a gas, electric, or oil bill, Claude reads it, and pure TypeScript does the math: yearly savings, Mass Save rebates, payback. 140+ unit and property-based tests, plus a ranking of 1,249 Boston buildings from the city's BERDO energy data. Built solo at Hackachusetts 2026.
`Next.js` `TypeScript` `Claude API` `Zod` `Vitest`

**📚 [BookFlix](https://github.com/kroy2022/560-Project)** · Team project
Full-stack digital library. Normalized SQL Server schema with ACID transactions over 2,000+ records, ASP.NET Core backend, React + TypeScript frontend with search, reviews, and auth.
`C#` `ASP.NET Core` `SQL Server` `React` `TypeScript`

**🛡️ [LLMGuard](https://github.com/aayush24rai/llm-integrity-attestation)** · [Paper](https://github.com/aayush24rai/llm-integrity-attestation/blob/main/LLMGuard-Paper.pdf) · [Poster](https://github.com/aayush24rai/llm-integrity-attestation/blob/main/LLMGuard-Poster.pdf)
Capstone research on catching tampering with a locally deployed LLM. Once a model is loaded, it's usually trusted blindly. LLMGuard is a layered design that pairs TPM + Linux IMA (load-time file integrity) with TEE-backed behavioral attestation (runtime), so each layer covers the other's blind spot. Includes a threat model, a comparison of five attestation approaches, and a 10-page IEEE-format paper.
`Security` `TPM` `Linux IMA` `TEE` `LLMs`

**🌾 [AguaCrop](https://github.com/aayush24rai/TAPS-2024-Hackathon)** · 🏆 1st Place, K-State TAPS Hackathon
RAG chatbot that answers irrigation questions in plain language, plus Scikit-learn models on agricultural and weather data that drive irrigation schedules in a React dashboard. Built in 48 hours.
`Python` `LangChain` `Scikit-learn` `Node.js` `React`
